Wacky Insights Shorts Automation

A personal automation application used by the owner of the Wacky Insights channel to prepare original short-form videos and upload them through the YouTube Data API.

What this application does

The application creates a finished video independently and then uses the YouTube Data API to upload that video and its metadata to the channel owner's own account. It is not offered as a public service and does not provide third-party users with access to the channel or account.

YouTube API functionality

The application uses Google OAuth 2.0 to authorize the channel owner and requests only the upload permission required for its upload functionality. It does not use the YouTube Data API for advertising, analytics, comment management, subscriber tracking, or profiling.
